さらに深く

  • ソースコード： github.com/yitzhakbg/AnkiTov —— AGPL-3.0ライセンス、CC0シードデッキ付き。
  • ドキュメント：mdBookサイトでアーキテクチャ、IMP、開発ガイドをカバー。
  • 動かす：まずbash scripts/bootstrap.sh、次に cd backend && cargo run start.
  • 探検する：ダッシュボード (/dashboard）とライブAPIドキュメント (/scalar）はサーバーに同梱。
  • コミュニティ： デッキテンプレート、カリキュラムのマッピング、パイロット支援.
