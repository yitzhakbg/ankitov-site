להעמקה

  • קוד המקור: github.com/yitzhakbg/AnkiTov — AGPL-3.0, עם חבילות פתיחה ב-CC0.
  • תיעוד: אתר ה-mdBook מכסה את הארכיטקטורה, את ה-IMP ואת מדריך המפתח.
  • מריצים: bash scripts/bootstrap.sh, ואז cd backend && cargo run start.
  • חוקרים: לוח הבקרה (/dashboard) ותיעוד ה-API החי (/scalar) מגיעים עם השרת.
  • קהילה: תבניות חבילות, מיפויי תוכנית לימודים ועזרה בפיילוט.
