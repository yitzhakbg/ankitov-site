더 깊이 들어가기

  • 소스 코드: github.com/yitzhakbg/AnkiTov — AGPL-3.0, CC0 시드 덱 포함.
  • 문서: mdBook 사이트에서 아키텍처, IMP, 개발 가이드를 다룹니다.
  • 실행하기: bash scripts/bootstrap.sh를 실행한 뒤 cd backend && cargo run start를 실행합니다.
  • 둘러보기: 대시보드 (/dashboard)와 실시간 API 문서 (/scalar)는 서버와 함께 제공됩니다.
