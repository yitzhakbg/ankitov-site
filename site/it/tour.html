Approfondisci

  • Codice sorgente: github.com/yitzhakbg/AnkiTov — AGPL-3.0, con mazzi CC0.
  • Documentazione: il sito mdBook copre l'architettura, l'IMP e la guida per sviluppatori.
  • Esegui: bash scripts/bootstrap.sh, poi cd backend && cargo run start.
  • Esplora: la dashboard (/dashboard) e la documentazione API live (/scalar) sono incluse nel server.
  • Comunità: modelli di mazzi, mappature curricolari e aiuto per le sperimentazioni.
