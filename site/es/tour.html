Ve más a fondo

  • Código fuente: github.com/yitzhakbg/AnkiTov — AGPL-3.0, con mazos semilla CC0.
  • Documentación: el sitio mdBook cubre la arquitectura, el IMP y la guía de desarrollo.
  • Ejecútalo: bash scripts/bootstrap.sh y después cd backend && cargo run start.
  • Explóralo: el panel (/dashboard) y la documentación de la API en vivo (/scalar) vienen con el servidor.
  • Comunidad: plantillas de mazos, mapeos curriculares y ayuda para pilotos.
