Копните глубже

  • Исходный код: github.com/yitzhakbg/AnkiTov — AGPL-3.0, со стартовыми колодами под CC0.
  • Документация: сайт на mdBook описывает архитектуру, IMP и руководство для разработчиков.
  • Запуск: bash scripts/bootstrap.sh, затем cd backend && cargo run start.
  • Исследуйте: дашборд (/dashboard) и живая документация API (/scalar) поставляются вместе с сервером.
  • Сообщество: шаблоны колод, привязки к программе и помощь с пилотом.
