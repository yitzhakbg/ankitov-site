تعمّق أكثر

  • الشيفرة المصدرية: github.com/yitzhakbg/AnkiTov — برخصة AGPL-3.0، مع حزم بذور برخصة CC0.
  • التوثيق: موقع mdBook يغطي المعمارية، وخط الإتقان المتشابك (IMP)، ودليل المطوّر.
  • شغّله: bash scripts/bootstrap.sh، ثم cd backend && cargo run start.
  • استكشفه: لوحة التحكم (/dashboard) ووثائق API الحية (/scalar) تأتي مع الخادم.
  • المجتمع: قوالب حزم، وربطات مناهج، ومساعدة في التجارب.
