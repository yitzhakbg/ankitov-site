深入了解

  • 源代码： github.com/yitzhakbg/AnkiTov — AGPL-3.0 许可，附带 CC0 种子牌组。
  • 文档： mdBook 站点涵盖架构、IMP 与开发指南。
  • 运行： bash scripts/bootstrap.sh，然后 cd backend && cargo run start。
  • 探索： 仪表盘 （/dashboard）与实时 API 文档 （/scalar）随服务器一同提供。
  • 社区： 牌组模板、课程映射与试点支持。
