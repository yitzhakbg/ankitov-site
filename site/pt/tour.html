Aprofunde-se

  • Código-fonte: github.com/yitzhakbg/AnkiTov — AGPL-3.0, com baralhos iniciais CC0.
  • Documentação: o site em mdBook cobre a arquitetura, o IMP e o guia de desenvolvimento.
  • Rode: bash scripts/bootstrap.sh, depois cd backend && cargo run start.
  • Explore: o dashboard (/dashboard) e a documentação da API ao vivo (/scalar) já vêm com o servidor.
  • Comunidade: modelos de baralhos, mapeamentos curriculares e ajuda com pilotos.
